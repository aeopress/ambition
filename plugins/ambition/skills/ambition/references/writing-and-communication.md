# Writing and communication

Use this reference for prose, including documentation, speeches, essays, announcements, scripts, email, posts, and cover letters. Use only the selected axis. These methods guide one rewritten prompt. They do not start the writing task.

## Outcome

Name the change sought in the reader's action, belief, or feeling. Text serves that change.

Some tasks require the text itself. Preserve a personal essay, an apology, or a piece that carries the author's voice. Improve its craft through Depth. Do not replace the piece with a different project.

For documentation, success means that readers can locate an answer and complete their work. An Altitude rewrite can instead remove the need for a page through a clearer error, a better default, or an executable example. Choose that replacement only when it preserves the user's outcome and authority. Do not add it beside the requested page.

## Raw material

Read the author's earlier work to learn the voice. Inspect the primary documents behind the claims. Use transcripts, replies to earlier publications, support cases, search terms, and questions from actual readers.

A template or an existing draft is useful context. Neither can replace evidence about the author, the subject, and the audience.

## Methods and tools

| Weak approach | Method to put in the rewrite |
|---|---|
| Trusting a visual proofread | Read the text aloud. Use a readability check. Verify factual statements with original sources. |
| Accepting the first structure | Compare two distinct openings or structures internally. Set the comparison criteria before drafting. Deliver only the selected piece. |
| Expanding the text | Cut about one third internally. Restore only content whose loss harms the purpose. |
| Revising sentences before the argument | Build a reverse outline with one summary per paragraph. Check the sequence before polishing. |
| Assuming what the audience needs | Collect questions from real readers. Check the draft against each question. |
| Drafting without a point | State the central claim in one sentence. Build an outline that supports that claim. |

## Other fields worth borrowing from

- **Teaching:** show a worked example before a general rule. Check whether readers can use the rule.
- **Rhetoric:** identify the strongest objection. Address it before it blocks understanding.
- **Journalism:** open with the news, support claims with sources, and choose what to omit.
- **UX writing:** observe whether readers can finish the intended task with the text.
- **Screenwriting:** establish stakes, arrange the sequence, and enter a scene after unnecessary setup.

## Judges

Use several limited checks when no single test can settle quality. Match each check to the claim it can support.

- Test the text with a member of the intended audience. If that is unavailable, check it against questions that represent that audience. State that this checks coverage rather than real reader behavior.
- Ask an unfamiliar reader to restate the point from the text alone. Compare the restatement with the intended claim. A model's restatement can expose ambiguity, but agreement between models is no outside signal of reader success.
- Compare the selected draft blindly with a simpler baseline. Use criteria fixed before either draft. Prefer judgments from actual readers.
- Verify each factual assertion against its source.

Separate tested facts, inferences, and taste. If quality remains hard to measure, name the closest reader test and the uncertainty in the rewrite. A small excerpt can serve as an internal test unit within the existing task. Do not add a feedback round or a second deliverable here.

## Targets and vetoes

Possible targets include these:

- Keep the useful content in half as many words.
- Convey the point to an unfamiliar reader within 30 seconds.
- Answer the full set of reader questions.

Choose a task-specific target above what a plain draft would achieve.

Preserve factual accuracy, the author's voice, the relationship with the reader, and the required tone. Required length and format also veto a proposed target.

## Traps

- More words, headings, or ornament can obscure the same weak argument.
- A model's claim that its prose persuades people provides no measurement.
- Smooth generic prose can erase the author's voice.
- A personal piece does not authorize a publishing or marketing program.
